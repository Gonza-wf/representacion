# 🚀 Showcase Interactivo — Laboratorio de Componentes Web

Un completo laboratorio interactivo de frontend de alto rendimiento construido con **Vanilla JavaScript**, **CSS Moderno** y **Vite**, diseñado para demostrar habilidades técnicas de desarrollo web a través de **8 mini-aplicaciones totalmente funcionales**.

![Preview](public/og-preview.jpg)

---

## ✨ Características Principales

### 🎮 Mini-Aplicaciones Interactivas
1. **🛒 E-commerce:** Catálogo con filtros por categoría y precio, buscador en tiempo real, favoritos, modal de producto detallado y carrito de compras deslizante con checkout simulado y notificaciones toast.
2. **📊 Dashboard Empresarial:** Tarjetas KPI con tendencias porcentuales, gráfico semanal interactivo con Chart.js (responsive resize), tabla de pedidos ordenable y panel de inventario crítico en tiempo real con reposición interactiva.
3. **📅 Reserva de Turnos:** Stepper guiado de 4 pasos (Servicio → Selección de día hábil dinámico → Franja horaria con ocupación simulada → Formulario de confirmación con validación).
4. **🖼️ Galerías & Comparativas:** Slider interactivo de Antes/Después con presets de industria, carrusel automático con pausa on-hover, slider manual con soporte táctil (swipe) y galería masonry con Lightbox a pantalla completa.
5. **📝 Formularios Avanzados:** Pestañas de Login y Registro con medidor de fuerza de contraseña en vivo, conmutador de visibilidad de contraseña + Formulario Wizard multi-paso de 3 etapas con validaciones.
6. **📋 Tablero Kanban:** Sistema Drag & Drop nativo entre columnas (Por Hacer, En Progreso, Completado), etiquetas de prioridad y creación de tarjetas.
7. **⚡ API REST Explorer:** Consumo asíncrono real desde JSONPlaceholder (GET usuarios/posts, POST simulado, manejo de error 404, esqueletos de carga y medición de latencia en milisegundos).
8. **🗺️ Mapa Interactivo Leaflet:** OpenStreetMap con cambio a modo nocturno (CartoDB Dark), 6 sucursales geolocalizadas con marcadores animados, popups y radio de cobertura.

---

### 💎 Experiencia de Usuario & Extras
* **📱 Simulador Responsive:** Botones para previsualizar todos los componentes en formato Mobile (375px), Tablet (768px), Notebook (1024px) y Desktop (100%).
* **🌓 Modo Claro / Oscuro:** Conmutador persistente en `localStorage` con transiciones suaves en toda la interfaz.
* **🔊 Sonidos Web Audio:** Sistema de efectos sonoros nativos sintetizados con la Web Audio API (sin archivos externos de audio).
* **🔔 Sistema Global de Toasts:** Notificaciones flotantes con animaciones, barras de progreso y temporizador.
* **📱 Menú Deslizante Mobile:** Drawer lateral optimizado para navegación rápida en celulares.
* **💬 Cotizador con WhatsApp:** Modal interactivo que recopila los requerimientos del cliente y genera un mensaje formateado listo para enviar a WhatsApp.

## 🛠️ Tecnologías Utilizadas

* **HTML5 Semántico** & **CSS3 Moderno** (Variables CSS, Flexbox, Grid, Glassmorphism, Animaciones fluidas).
* **JavaScript ES6+ (Vanilla)** sin frameworks pesados, manipulación directa y eficiente del DOM.
* **[Vite](https://vitejs.dev/)** para desarrollo ultrarrápido y empaquetado optimizado para producción.
* **[Chart.js](https://www.chartjs.org/)** para gráficos estadísticos interactivos.
* **[Leaflet](https://leafletjs.com/)** para mapas interactivos y capas de azulejos.
* **[SortableJS](https://sortablejs.github.io/Sortable/)** para el sistema Kanban Drag & Drop.
* **[FontAwesome](https://fontawesome.com/)** para iconografía moderna.

## 🚀 Instalación y Puesta en Marcha

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Gonza-wf/representacion.git
   cd representacion
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilar para producción:**
   ```bash
   npm run build
   ```

5. **Previsualizar la versión de producción:**
   ```bash
   npm run preview
   ```
